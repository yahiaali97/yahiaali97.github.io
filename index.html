    04How I test

    From requirement to release

    1. Understand the business

      Read the business documents and user stories, and check they match the real objectives.

    2. Define acceptance criteria

      Agree on inputs, outputs and what "done" means with project managers and developers.

    3. Design test cases

      Write detailed test cases in Azure DevOps, Excel or BrowserStack, covering happy paths and edge cases.

      Azure DevOpsBrowserStack

    4. Execute and automate

      Run functional, UI and API tests on web and mobile, and automate the repeatable ones.

      PlaywrightSeleniumPostman

    5. Validate the data

      Query SQL Server to confirm what the UI shows is what the database holds.

      SQL Server

    6. Report, track, regress

      Write clear bug reports, follow them to the fix, and keep regression running every release.

      JIRAAllure
